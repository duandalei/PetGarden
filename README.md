# PetGarden · 班级宠物园（项目交接包）

这是一个给另一个 AI Agent 的**项目交接包**，不是已经写好的代码。

PetGarden 是一个本地优先、离线可用的课堂宠物养成工具：老师给学生的课堂表现加减分，宠物实时成长、变表情、升级；全班宠物可以投到教室大屏上。项目从零实现，技术栈为 uv + FastAPI + SQLite + Vue 3 + TypeScript，宠物全部用内联 SVG + CSS 动画绘制。

## 三个关键决策

### 1. 宠物用「内联 SVG + CSS 动画」程序化绘制，不用图片

**可以做到，而且比静态图片更适合课堂场景。**

- 每只宠物由几十个 SVG 图形（头、耳朵、眼睛、尾巴、身体、饰品）组合而成，不是一张图。
- 呼吸、摇头、眨眼、耳朵抖动、尾巴摆动全部用 CSS `@keyframes` 驱动，只动 `transform` 和 `opacity`，不占主线程。
- 开心 / 一般 / 低落三套表情由积分实时决定；加分时触发欢呼动画，升级时触发进化光环，减分时是温柔的「耷拉耳朵」而不是惩罚性抖动。
- 5 个成长阶段通过体型、颜色饱和度、围巾、徽章、光环、皇冠逐步变化，同一套几何图形复用。
- 所有宠物都是矢量、可换色、无外部资源、断网可用、投影不糊。

代价是：程序化 SVG 的「插画精致度」不如 AI 生成的静态图。项目用**强剪影、有限配色、统一描边、阶段饰品**来保证辨识度和可爱度。如果以后想要更丰富的画风，可以在 `PetSprite` 组件后面换一套 sprite-sheet 渲染器，业务层不用改。

参考原型：`reference/pet-sprite-demo.html`。双击即可打开，不依赖网络。
小技巧：在地址后加 `?species=dragon&score=90&mood=happy`，可直接预览青龙 Lv5 的传说形态。

### 2. SQLite + uv

- 数据库：项目内 `data/petgarden.db`，启用 WAL、外键，无需安装任何数据库服务。
- Python：`uv` 管理，`.venv` 建在项目内，`pyproject.toml` + `uv.lock` 锁定依赖；不依赖其他 Python 环境管理器，不污染全局 Python。
- 运行时完全离线：不请求 CDN、不加载外部字体、不调用任何云服务。

### 3. 单教师、本地优先、PIN 保护

- 不做多教师、学生账号、云同步。
- 教师 4–6 位 PIN + HttpOnly 签名 Cookie；首次启动引导设置。
- 班级、学生、积分、养宠进度全部存在本机；支持 JSON 导出/导入备份。
